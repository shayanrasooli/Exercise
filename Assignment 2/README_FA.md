# پروژه پیشرفته Python: تحلیل ثبت‌نام، پرداخت و گواهی‌های آموزشگاه

## صورت مسئله

یک آموزشگاه برای مدیریت دوره‌های برنامه‌نویسی از چند فایل JSON استفاده می‌کند. مدیر آموزشگاه به گزارشی نیاز دارد که فقط بر اساس اطلاعات معتبر ساخته شده باشد و وضعیت ثبت‌نام، نمره، پرداخت و صدور گواهی را هم‌زمان نشان دهد.

اطلاعات در چهار فایل جداگانه نگهداری می‌شوند. بعضی داده‌ها تکراری، ناقص، ناسازگار یا نامعتبر هستند. شما باید فایل `main.py` را تکمیل کنید تا اطلاعات را بخواند، اعتبارسنجی کند و گزارش نهایی بسازد.

## فایل‌های ورودی

| فایل | محتوا |
|---|---|
| `students.json` | مشخصات دانش‌آموزان و وضعیت فعال بودن آن‌ها |
| `courses.json` | کاتالوگ دوره‌ها، شهریه، حداقل نمره قبولی و پیش‌نیازها |
| `enrollments.json` | ثبت‌نام دانش‌آموزان در دوره‌ها و نمرات آن‌ها |
| `payments.json` | پرداخت‌ها و برگشت وجه‌ها (Refund) |
| `main.py` | برنامه ناقص با ۳۸ جای خالی |

ابتدا هر چهار فایل JSON را باز کنید و ساختار داده‌ها را بررسی کنید. سپس سراغ تکمیل `main.py` بروید. کامنت کنار هر جای خالی هدف همان بخش را توضیح می‌دهد؛ اما لازم است خودتان راه‌حل را بنویسید.

## قوانین کسب‌وکار

### الف) اعتبارسنجی ثبت‌نام‌ها

1. فقط دانش‌آموزانی قابل قبول‌اند که در `students.json` وجود دارند و `active` آن‌ها برابر `true` است.
2. کد دوره و وضعیت ثبت‌نام ممکن است حروف کوچک یا فاصله اضافی داشته باشد؛ قبل از مقایسه باید استاندارد شوند.
3. فقط دوره‌هایی معتبرند که در `courses.json` تعریف شده باشند.
4. وضعیت‌های مجاز ثبت‌نام `COMPLETED` و `IN_PROGRESS` هستند.
5. نمره باید یا `null` باشد یا عددی بین ۰ تا ۱۰۰. ثبت‌نام `COMPLETED` حتماً باید نمره داشته باشد.
6. هر دانش‌آموز برای هر دوره فقط یک ثبت‌نام معتبر دارد. اگر ترکیب دانش‌آموز و دوره تکرار شد، اولین رکورد معتبر نگه داشته می‌شود.
7. اطلاعات اصلی هر ثبت‌نام باید حفظ شود؛ فقط کد دوره و وضعیت آن با مقدار استاندارد جایگزین می‌شوند.

### ب) محاسبه پرداخت خالص

1. هر `transaction_id` فقط یک بار پردازش می‌شود؛ تکرار شناسه تراکنش نادیده گرفته می‌شود.
2. تراکنش فقط وقتی معتبر است که وضعیت آن `SUCCESS` و نوع آن `PAYMENT` یا `REFUND` باشد.
3. مبلغ باید عددی و بزرگ‌تر از صفر باشد.
4. تراکنش فقط برای ترکیب دانش‌آموز و دوره‌ای پذیرفته می‌شود که ثبت‌نام معتبر داشته باشد.
5. `PAYMENT` به مبلغ پرداخت‌شده اضافه می‌کند و `REFUND` از آن کم می‌کند.
6. پرداخت خالص هر ثبت‌نام برابر مجموع پرداخت‌های موفق منهای مجموع برگشت وجه‌های موفق است.

### پ) صدور گواهی

برای اینکه دانش‌آموز گواهی یک دوره را دریافت کند، باید تمام شرایط زیر برقرار باشند:

1. ثبت‌نام او در آن دوره `COMPLETED` باشد.
2. نمره او حداقل برابر `pass_score` دوره باشد.
3. تمام پیش‌نیازهای دوره را قبلاً با موفقیت گذرانده باشد.
4. پرداخت خالص او حداقل برابر شهریه دوره باشد.

**نکته مهم:** ترتیب دوره‌ها در `courses.json` عمدی است؛ دوره‌های پیش‌نیاز قبل از دوره‌های وابسته آمده‌اند. ترتیب را تغییر ندهید، چون برنامه باید گواهی دوره‌های پایه را پیش از بررسی دوره‌های پیشرفته ثبت کند.

## گزارش نهایی باید چه چیزهایی داشته باشد؟

- تعداد کل دانش‌آموزان و تعداد دانش‌آموزان فعال
- تعداد ردیف‌های ثبت‌نام و تعداد ثبت‌نام‌های معتبر و یکتا
- تعداد تراکنش‌های نادیده‌گرفته‌شده
- برای هر دوره: تعداد دانش‌آموزان، میانگین نمره و درآمد خالص
- فهرست دانش‌آموزان هر دوره
- فهرست گواهی‌های صادرشده
- فهرست ثبت‌نام‌هایی که هنوز بدهی دارند
- دوره‌هایی که هیچ ثبت‌نام معتبر ندارند
- دوره‌های تأییدشده هر دانش‌آموز فعال

## مفاهیم Python مورد انتظار

- List برای نگهداری ردیف‌ها، نمره‌ها و گزارش‌ها
- Tuple برای ساخت کلید مرکب `(student_id, course_code)`
- Set برای تشخیص رکورد تکراری، نگهداری دوره‌های معتبر و بررسی پیش‌نیازها
- Dictionary برای نمایه‌سازی، گروه‌بندی، شمارش و نگهداری مبالغ
- حلقه‌های `for` و شرط‌های `if / elif / else`
- `get()`, `setdefault()`, `append()`, `add()`, `issubset()`, `update()`
- Dictionary unpacking با `**`
- خواندن فایل با `pathlib` و `json`

## محدودیت‌ها

- از `Counter` و `defaultdict` استفاده نکنید.
- از کتابخانه‌های خارجی استفاده نکنید.
- فایل‌های JSON را برای درست شدن خروجی به‌صورت دستی تغییر ندهید.
- از روی داده‌ها جواب را Hard-code نکنید؛ برنامه باید با اضافه شدن ردیف‌های جدید نیز کار کند.
- ترتیب رکوردها در فایل‌ها را حفظ کنید؛ در موارد تکراری، اولین رکورد معتبر ملاک است.

## اجرا

هر پنج فایل را در یک پوشه نگه دارید و اجرا کنید:

```bash
python main.py
```

تا زمانی که همه جای خالی‌ها تکمیل نشده‌اند، برنامه اجرا نخواهد شد.
